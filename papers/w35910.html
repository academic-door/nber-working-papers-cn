Infinite Factor Structure in Conditional Asset Pricing

条件资产定价中的无限因子结构

Mikhail Chernov, Bryan T. Kelly, Semyon Malamud, Johannes Schwab

金融与资产定价 未指明区域

Abstract

The return covariance matrix is widely assumed to have an eigenvalue cliff: a few large eigenvalues, then a bounded bulk, as in the approximate factor structure of Chamberlain and Rothschild (1983). This premise underlies factor tests, principal-component methods, and large-covariance estimation. These methods estimate moments from returns pooled across states, so they necessarily view a conditional world unconditionally. We show that, generically, this view removes the cliff: a conditional model with a few factors is, unconditionally, an infinite-factor model in which infinitely many eigenvalues diverge. This holds for the characteristic-managed portfolios that machine-learning methods trade, and for individual stocks whose loadings differ persistently across firms. Yet as long as conditional expected returns admit no asymptotic arbitrage, the maximal Sharpe ratio stays finite. For generic expected returns, infinitely many components are priced, so no finite set of principal components spans expected returns. Reducing returns to a few principal components therefore discards priced risk.

中文摘要

收益率协方差矩阵被广泛假设具有特征值悬崖：少数大特征值，然后是有界的主体，如Chamberlain和Rothschild（1983）的近似因子结构。这一前提是因子检验、主成分方法和大协方差估计的基础。这些方法从跨状态合并的收益率中估计矩，因此它们必然以无条件视角看待条件世界。我们表明，一般而言，这种视角消除了悬崖：一个具有少数因子的条件模型，在无条件意义下是一个无限因子模型，其中无限多个特征值发散。这适用于机器学习方法交易的特征管理组合，以及载荷在不同公司间持续不同的个股。然而，只要条件预期收益率不存在渐近套利，最大夏普比率就保持有限。对于一般预期收益率，无限多个成分被定价，因此没有有限的主成分集合能够张成预期收益率。因此，将收益率缩减为少数主成分会丢弃被定价的风险。
